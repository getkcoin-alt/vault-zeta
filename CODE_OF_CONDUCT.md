# Code of Conduct

Vault Zeta is an experiment around memory, continuity and long-running AI systems. Those topics can get philosophical quickly, but the repository should stay technically useful.

Please:

- critique ideas and code rather than people
- separate measured behavior from speculation
- say when something is a hypothesis
- respect privacy and never post somebody else's personal data
- give credit for prior work
- keep disagreements specific enough that another contributor can learn from them

Harassment, threats, discriminatory abuse, doxxing, deliberate credential exposure and repeated personal attacks are not welcome.

For a conduct problem that should not be handled publicly, contact **karnveer@scriza.in**.

The goal is not corporate politeness. It is a place where people can disagree hard about architecture without making collaboration miserable.
