# Support

Vault Zeta is a public alpha.

For reproducible bugs and focused feature requests, use GitHub Issues.

When reporting a problem, include:

- Python version
- operating system
- Vault Zeta version/commit
- the smallest reproduction you can make
- relevant output with private data removed

Do not upload real memory databases, customer data, credentials or personal datasets.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public issue.
